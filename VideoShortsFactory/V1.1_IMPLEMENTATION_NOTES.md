## Nové soubory k přidání do Xcode projektu

**DŮLEŽITÉ:** Před buildem musíte přidat tyto soubory do Xcode projektu:

### 1. Utils složka:
- `VideoShortsFactory/Utils/DesignTokens.swift`
- `VideoShortsFactory/Utils/ColorExtensions.swift`

### 2. Views složka:
- `VideoShortsFactory/Views/HeaderView.swift`
- `VideoShortsFactory/Views/FooterView.swift`

### 3. Components složka:
- `VideoShortsFactory/Views/Components/HansWalkerButton.swift`

### 4. Resources složka:
- `VideoShortsFactory/Resources/Fonts/KronaOne-Regular.ttf`

## Jak přidat soubory do Xcode:

1. Otevřete `VideoShortsFactory.xcodeproj` v Xcode
2. V Project Navigatoru (levý panel):
   - Klikněte pravým tlačítkem na složku `Utils` → "Add Files to VideoShortsFactory..."
   - Vyberte `DesignTokens.swift` a `ColorExtensions.swift`
   - Ujistěte se, že je zaškrtnuto "Copy items if needed" a "VideoShortsFactory" target
   
3. Opakujte pro Views a Components složky
4. Pro font:
   - Klikněte pravým na `Resources` → "Add Files..."
   - Vyberte `Fonts` složku
   - **DŮLEŽITÉ:** Ujistěte se že font je přidán do target membership!
