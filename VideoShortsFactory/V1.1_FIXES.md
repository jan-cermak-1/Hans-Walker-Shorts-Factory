# v1.1 Opravy - 2026-03-02

## Provedené změny

### 1. ✅ Opraveno zobrazení loga
**Problém:** Logo se zobrazovalo jako černý obdélník místo Hans Walker loga

**Řešení:**
- Zkopírován nový PNG obrázek loga do `Assets.xcassets/hans-walker-logo.imageset/`
- Odstraněn `.renderingMode(.template)` z `HeaderView.swift`
- Logo se nyní zobrazuje v plných barvách (ne jako šablona)

**Změněné soubory:**
- `VideoShortsFactory/Assets.xcassets/hans-walker-logo.imageset/hans-walker-logo@2x.png`
- `VideoShortsFactory/Views/HeaderView.swift` (řádky 10-14)

### 2. ✅ Povolena změna šířky okna
**Problém:** Aplikace umožňovala měnit pouze výšku, ne šířku

**Řešení:**
- Změněna window resizability z `.contentMinSize` na `.contentSize`
- Nyní lze měnit jak šířku, tak výšku okna

**Změněné soubory:**
- `VideoShortsFactoryApp.swift` (řádek 15)

**Před:**
```swift
.windowResizability(.contentMinSize)
```

**Po:**
```swift
.windowResizability(.contentSize)
```

### 3. ✅ Zkontrolován kontrast barev (WCAG 2.1)
**Výsledek:** Všechny kombinace barev splňují WCAG 2.1 Level AA

**Hlavní zjištění:**
- Hlavní text (ink na cream): **11.8:1** ✅ AA + AAA
- Text na kartách: **10.9:1** ✅ AA + AAA
- Sekundární text: **6.9:1** ✅ AA (ne AAA, ale je to v pořádku)
- Text na zeleném tlačítku: **4.9:1** ✅ AA (nad limitem 4.5:1)
- Dark mode hlavní text: **12.2:1** ✅ AA + AAA

**Dokumentace:**
- Vytvořen `CONTRAST_ANALYSIS.md` s detailní analýzou všech kontrastů
- Žádné změny barev nejsou nutné

### 4. ✅ Opraven styl tlačítka
**Problém:** Letter-spacing byl příliš velký (3.2 místo 2.2)

**Řešení:**
- Opraven letter-spacing pro Krona One font (11pt × 0.2em = 2.2)
- Text na tlačítku nyní odpovídá webové verzi
- Vylepšen komentář pro lepší pochopení

**Změněné soubory:**
- `VideoShortsFactory/Views/Components/HansWalkerButton.swift` (řádky 44-47, 49-53)

**Před:**
```swift
.tracking(3.2) // letter-spacing: 0.2em
```

**Po:**
```swift
.tracking(2.2) // letter-spacing: 0.2em (20% of 11pt)
```

**Také zpřesněn komentář pro barvu textu:**
```swift
.foregroundColor(
    disabled 
        ? Color.hwTextSecondary(colorScheme).opacity(0.5) 
        : Color.hwInk  // Always dark ink (#2C1F14), not adaptive
)
```
