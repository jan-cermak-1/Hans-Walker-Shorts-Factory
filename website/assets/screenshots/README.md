# Screenshots

This folder contains screenshots of the Hans Walker Shorts Factory application.

## Required Screenshots

1. **light-mode.png** - Application in light mode (540x840px recommended)
2. **dark-mode.png** - Application in dark mode (540x840px recommended)
3. **processing.png** - Application while processing videos (540x840px recommended)

## How to Create Screenshots

1. Build and run the application
2. Use macOS Screenshot tool (⌘+Shift+4)
3. Capture the application window
4. Save as PNG format
5. Place in this folder with the names above

## Guidelines

- **Resolution**: Use @2x retina resolution
- **Format**: PNG with transparency if applicable
- **Content**: Show real UI elements, avoid placeholder content
- **Size**: Keep file size under 1MB per screenshot (use compression if needed)

---

Screenshots will be automatically displayed on the website once added to this folder.
