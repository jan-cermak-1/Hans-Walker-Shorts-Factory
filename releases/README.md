# Hans Walker Shorts Factory — Releases

This folder contains compiled application builds ready for distribution.

## Latest Release: v1.1.0

### Download

- **DMG Installer**: `Hans-Walker-Shorts-Factory-v1.1.0.dmg` (Recommended)
- **ZIP Archive**: `Hans-Walker-Shorts-Factory-v1.1.0.app.zip`

### Installation

#### From DMG (Recommended)
1. Download the `.dmg` file
2. Open the DMG file
3. Drag "Hans Walker Shorts Factory" to your Applications folder
4. Eject the DMG
5. Open the app from Applications

#### From ZIP
1. Download the `.zip` file
2. Extract the archive
3. Move "Hans Walker Shorts Factory.app" to your Applications folder
4. Right-click the app and select "Open" (first time only, due to macOS Gatekeeper)

### System Requirements

- **macOS**: 13.0 (Ventura) or later
- **Processor**: Apple Silicon (M1/M2/M3) or Intel
- **Memory**: 4GB RAM minimum (8GB recommended)
- **Storage**: 200MB for app + space for video processing

### What's New in v1.1.0

#### Features
- ✅ Complete Hans Walker brand integration with custom logo
- ✅ Krona One custom font throughout the application
- ✅ Custom design system with Hans Walker color palette
- ✅ Removed macOS title bar, integrated header into window chrome
- ✅ Fixed window width (540px), adaptive height (840px or 90% screen)
- ✅ Comprehensive hover effects for all interactive buttons
- ✅ 3D button styling matching web design reference
- ✅ WCAG 2.1 Level AA accessibility compliance
- ✅ Dark mode support with appropriate logo variants

#### Improvements
- Larger, centered header with prominent branding
- Clean, professional appearance without title bar
- Smooth animations and visual feedback
- Better horizontal space utilization
- Enhanced user experience

#### Technical
- Centralized design tokens in DesignTokens.swift
- Reusable component library (HansWalkerButton, HeaderView, FooterView)
